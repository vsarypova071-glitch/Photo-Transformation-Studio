
# AI Studio | Identity Lock 4.5

Профессиональный инструмент для создания портретов.

## Как запустить:
1. Создайте папку проекта.
2. Создайте в ней папки `js` и `css`.
3. Сохраните файлы:
   - `index.html` (в корень)
   - `js/app.js`
   - `css/style.css`
4. Откройте `index.html` в браузере (желательно через Live Server для работы API).

## Особенности:
- **14 стилей:** Полный набор премиальных стилей.
- **Full Body:** Опция генерации во весь рост.
- **Glass UI:** Современный дизайн.
